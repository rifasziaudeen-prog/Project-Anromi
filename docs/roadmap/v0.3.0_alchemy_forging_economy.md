- [x] **Herb & Material Registry:** ✅ v0.3.0 — `core/balance.py` HERBS/MINERALS + gathering engine
  - 5 Element herbs, beast cores, spirit crystals, heaven-earth essence liquids.
  - Herb age scaling: 100-Year, 500-Year, 1,000-Year, 10,000-Year herbs (Higher age = exponential potency & recipe success).
- [x] **Alchemy Engine (*Dan Dao*):** ✅ v0.3.0 — `services/alchemy_engine.py` (impurity-driven grading per user design)
  - **Pill Recipes:** ✅ Breakthrough Boosters: *Qi Gathering Pill*, *Foundation Establishment Pill*, *Core Condensation Pill*, *Nascent Soul Formation Pill*. Healing/Lifespan/Dao-Heart: *Nine-Turns Soul Replenishing Pill*, *Life-Extending Rejuvenation Pill*. Rebirth: *Heaven-Defying Rebirth Pill*. + *Marrow Cleansing Pill*.
  - **Alchemy Crafting Simulation:** ✅ Furnace tier + Spiritual Flame type + Alchemy Mastery level. Output Quality driven by IMPURITY value (mastery lowers center & narrows spread; luck only fires heavenly coincidences): Low / Medium / Top / Flawless.
  - **Pill Toxicity (*Dan Du*) Mechanic:** ✅ Impure pills accumulate toxicity [0,100] on consumption; stalls Qi absorption (−60% max) and spikes breakthrough failure (+15% penalty max). Flawless pills = ZERO toxicity. Cleansed by Marrow Cleansing Pills or meditation decay.
- [x] **Artifact Forging Engine (*Qi Dao*):** ✅ v0.3.0 — `services/forging_engine.py`
  - Flying Swords, Defensive Armors, Spirit Banners, Tribulation Lightning Rods (4 equip slots; qi bonuses live now, tribulation resistance consumed by v0.4).
  - Artifact Tiers: Mortal -> Magical Treasure -> Spirit Treasure -> Dao Artifact -> Primordial Treasure (tier-scaled success; failure consumes half materials).
- [x] **Spiritual Stone Economy:** ✅ v0.3.0 — `services/economy_engine.py`
  - Low-Grade, Mid-Grade, High-Grade, and Top-Grade Spirit Stones (100:1 conversion ratio) with auto-breakdown payment.
  - Wandering Merchant pavilion with daily UTC-seeded stock rotation (deterministic FOMO).

### 2. Endpoints
- `POST /api/alchemy/refine` — Attempt pill alchemy with materials and furnace selection.
- `POST /api/inventory/consume` — Consume pill, applying instant Qi, breakthrough bonuses, and pill toxicity.
- `POST /api/forging/craft` — Forge spiritual artifacts with elemental materials.
