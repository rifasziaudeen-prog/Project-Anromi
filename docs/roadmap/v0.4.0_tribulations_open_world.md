**Target Version:** `0.4.0`

## 🎯 Scope & Objectives

### 1. Heavenly Tribulations Engine (*Tianjie*)
- [x] **Cosmic Trigger Rules:** ✅ v0.4.0 — successful major leaps into Realm ≥ 4 auto-summon the storm (`TRIBULATION_REQUIRED`); realm advances only on survival.
  - Mandatory for major realm crossings starting at **Nascent Soul (Realm 4)** and escalating all the way to **Eternal Transcendent (Realm 16)**.
- [x] **Tribulation Scale Tiers:** ✅ v0.4.0 — talent (root rarity) + karma_sin select the tier
  - **Four-Nine Tribulation (36 Strikes):** Standard Nascent Soul breakthrough.
  - **Six-Nine Tribulation (54 Strikes):** High-talent or high-karma cultivators.
  - **Nine-Nine Heavenly Tribulation (81 Strikes):** Heavenly / Divine Root cultivators defying heaven.
- [x] **Multi-Wave Mechanics & Formulas:** ✅ v0.4.0 — `services/tribulation_engine.py`
  - **Waves 1-2 (Physical Lightning):** gear soaks first (artifacts can SHATTER), physique resistance, overflow to pools.
  - **Wave 3 (Spiritual Lightning):** bypasses physical defense, direct pool/meridian damage.
  - **Wave 4 (Heart Demon Heavenly Fire):** willpower contest of Dao Heart vs karma-scaled illusions; zero Dao Heart = consumed from within.
- [x] **Tribulation Resolution Formula:** ✅ implemented as `D_base(target) × wave_mult(W) × (1 + 0.08·(b−1)) × (target/4)^1.35` with power-ratio mitigation cap — all tunable in `balance.TRIBULATION`.
  $$D_{strike}(W, b) = D_{base}(Realm) \times (1 + 0.40 \cdot (W-1)) \times (1 + 0.08 \cdot (b-1)) \times (T_{score})^{1.35}$$
- [x] **Mitigation & Artifact Sacrifice:** ✅ interactive per-wave actions: endure / sacrifice equipped artifact (nullifies whole wave, destroyed permanently) / Tribulation Shield Pill / bail out (survivable cowardice penalties).

### 2. Open-World Node Graph Engine (*Tianxia*)
- [x] **World Node Hierarchy:** ✅ v0.4.0 — 14 seeded nodes across Mortal Domain regions + Spirit Realm Gate (`balance.WORLD_NODES`, idempotently upserted into `world_nodes`).
  - **Planes:** Mortal Lower Plane → Spirit Realm → Immortal Plane (Spirit gate seeded; Immortal plane reserved).
  - **Regions:** Eastern Sea Archipelago, Southern Crimson Desert, Central Heavenly Sect Valley, Northern Ice Abyss, Western Demon Ridge.
- [x] **Node Properties:** ✅ spirit_density / elemental_bias / danger_tier (1–14 seeded) / adjacency JSON.
  - `spirit_density`: Multiplies passive meditation speed ($0.5\times$ to $10.0\times$). *(density stored & returned; meditation wiring is a one-line hook for next session)*
  - `elemental_bias`: Boosts matching root cultivation. *(same — data ready)*
  - `danger_rating`: Tier 1 to Tier 16 risk level. ✅ drives encounters, travel time, herb age tiers.
  - `available_actions`: Meditate, Forage Herbs, Mine Ore, Enter Ancient Ruin, Trade at Pavilion. ✅ via `/explore` + caravan access.
- [x] **Travel & Dynamic Encounter System:** ✅ Qi cost + danger-scaled cooldown lockouts; encounter table (herb/mineral finds scaled by danger, wandering caravan = merchant in the wilds, ancient cave abode gamble w/ legacy rewards or traps, demonic ambush clashes fight/flee — non-lethal outside tribulations per user's Balanced choice).
  - Traveling between nodes takes simulated time and Qi. ✅
  - **Encounter Probability Table:** ✅ weights shift with node danger (`ENCOUNTERS` config).

## 🏗️ Technical Architecture & Database Models

### 1. `models/world.py`
```python
class WorldNode(Base):
    __tablename__ = "world_nodes"
    id = Column(String, primary_key=True)
    name = Column(String, nullable=False)
    region = Column(String, nullable=False)
    plane = Column(String, default="Mortal Domain")
    spirit_density = Column(Float, default=1.0)
    elemental_bias = Column(String, default="Balanced")
    danger_tier = Column(Integer, default=1)
    connected_node_ids = Column(JSON, default=list) # Graph adjacency
```

### 2. Endpoints
- `GET /api/world/current-node` — Get current location, ambient Qi density, and available exploration actions.
- `POST /api/world/travel` — Move to an adjacent node (calculates travel events & encounters).
- `POST /api/world/explore` — Perform exploration roll on the current node.
- `POST /api/tribulation/initiate` — Enter the Heavenly Tribulation simulation.
