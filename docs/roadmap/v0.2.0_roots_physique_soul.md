**Target Version:** `0.2.0`  
**Milestone Goal:** Integrate 5-Element spiritual roots, mutant roots, ancient body constitutions, Dao Heart stability metrics, and the Hardcore Permadeath / Remnant Soul survival system.

## 🎯 Scope & Objectives
- [x] **Spiritual Roots System (*Linggen*):** ✅ v0.2.0 — `core/balance.py` ROOTS + `services/root_engine.py`
  - **Elemental Classes:** Metal (金), Wood (木), Water (水), Fire (火), Earth (土).
  - **Mutant Variations:** Lightning (雷), Wind (风), Ice (冰), Space (空).
  - **Purity Classes:**
    - *Pseudo-Root (4-5 Elements):* Slow absorption ($0.25\times$), high impurity accumulation.
    - *True Root (2-3 Elements):* Standard absorption ($1.0\times$).
    - *Heavenly Root (Single Element):* Exceptional absorption ($3.0\times$), zero bottleneck in Qi Condensation.
    - *Divine / Primordial Chaos Root:* Multi-element flawless harmony ($5.0\times$ + universal law affinity).
- [x] **Body Physiques (*Baoti*):** ✅ v0.2.0 — `core/balance.py` PHYSIQUES, rolled at registration
  - Ancient Sacred Body, Nine Nether Yin Body, Solar Divine Body, Immortal Mortal Body.
  - Grants passive physical defense, elemental damage absorption, and tribulation resilience.
- [x] **Dao Heart Stability (*Dao Xin*) & Heart Demon (*Xinmo*) Counter:** ✅ v0.2.0 — Qi Deviation in meditation route, `GET /api/cultivator/dao-heart/{id}`
  - Dao Heart Stability: $D_{heart} \in [0, 100]$.
  - Sin / Demonic Karma Accumulation: $K_{sin} \in [0, 1000]$.
  - If $D_{heart}$ drops below $30$, cultivator risks **Cultivation Deviation** (*Zou Huo Ru Mo*).
- [x] **Hardcore Permadeath & Remnant Soul Engine (*Canhun*):** ✅ v0.2.0 — `services/soul_engine.py` + `/api/soul/*`
  - **Pre-Nascent Soul Deaths (Realms 1-3):** Instant true death; character marked dead; Karmic Legacy points awarded based on achievements for the next lineage reincarnation.
  - **Nascent Soul & Above Deaths (Realms 4-16):**
    - Physical body is obliterated, but the **Nascent Soul escapes**.
    - Player enters **Remnant Soul State** with a decaying soul vitality timer ($S_{vitality}$).
    - **Survival Options Before Reincarnation:**
      1. *Possession (Duo She):* Attempt to forcibly possess an NPC mortal or lower-realm cultivator (Risk of severe soul backlash or karmic penalty). ✅
      2. *Puppet Vessel Forging:* Place the soul into a spiritual puppet core. ⏳ Planned (needs item system from v0.3.0)
      3. *Yin-Ghost Cultivation:* Cultivate as a bodiless Ghost Immortal (*Gui Xian*). ⏳ Planned
      4. *Ascended Reincarnation:* Voluntary reincarnate with high retained talent memory. ✅

## 🏗️ Technical Architecture

### 1. Soul State Machine
```
[ALIVE: Physical Vessel]
       │
       ▼ (Health <= 0 in Combat / Tribulation)
  [Realm Check]
    ├── Realm < Nascent Soul ───► [TRUE DEATH] ───► [Karmic Legacy Reincarnation]
    └── Realm >= Nascent Soul ──► [REMNANT SOUL STATE] (Timer Active)
                                        │
             ┌──────────────────────────┼─────────────────────────┐
             ▼                          ▼                         ▼
      [Body Possession]        [Puppet Vessel Reforging]   [Voluntary Reincarnation]
```

### 2. Schemas & APIs
- `POST /api/soul/possess` — Attempt soul possession of a target vessel.
- `POST /api/soul/reincarnate` — Finalize death and spend Karmic Legacy tokens on new character generation.
- `GET /api/cultivator/dao-heart` — Check mental stability and heart demon threshold.
