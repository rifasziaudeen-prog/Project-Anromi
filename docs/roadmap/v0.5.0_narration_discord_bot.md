# Phase Map: v0.5.0 — The Heavenly Dao Speaks (Narration) & Discord Bot Client

**Target Version:** `0.5.0`
**Milestone Goal:** Direction B begins — free-LLM narration layer + full Discord bot client. (Frontend deferred to v0.6.0.)

---

## 🎯 Scope & Objectives

### 1. Narration Engine — "The Heavenly Dao"
- [x] **Multi-provider fallback chain** (`services/narration_service.py`): OpenAI-compatible chat completions for all providers; priority from `.env` `NARRATION_PROVIDERS` (default `groq,gemini,openrouter`); automatic skip on rate limits / invalid keys / timeouts; canned fallback lines keep the game playable with zero keys.
- [x] **Verified current model IDs** (2026):
  - Groq: `openai/gpt-oss-120b` (flagship), `openai/gpt-oss-20b`, `llama-3.3-70b-versatile`, `groq/compound`
  - Gemini: `gemini-3.7-flash` (newest stable Flash; 3.6/3.5/2.5 lines also valid)
  - OpenRouter: any `:free` model (IDs rotate — check openrouter.ai/models)
- [x] **Persona voice in `core/balance.NARRATION`**: system prompt, event templates (breakthrough / tribulation_summoned / tribulation_survived / tribulation_destroyed / true_death / windfall / reincarnation / possession), temperature & token caps — editable like every other number.
- [x] **Endpoints**: `GET /api/narration/status`, `POST /api/narration/narrate/{discord_id}`, `GET /api/narration/events/recent`.

### 2. World Chronicle
- [x] **`models/events.py` GameEvent** append-only log; hooks wired into breakthrough, tribulation summon/survive/destroy, true death, windfall, reincarnation, possession.
- [x] Polling feed for the bot: `since_id` cursor semantics.

### 3. Discord Bot (`bot/`)
- [x] **Zero game logic** — pure aiohttp client (`bot/api_client.py`) against FastAPI.
- [x] Slash commands: register · stats · meditate · breakthrough · dao-heart · bag · recipes · refine · consume · craft · equip · map · travel · explore · merchant · buy · sell · convert · soul-state · possess · reincarnate · narrate.
- [x] **Interactive tribulations** (`bot/views.py`): button view (⚔️ Endure · 💊 Pill · 🗡️ Sacrifice Sword/Armor · 🏳️ Bail), one wave per click with live pool bars.
- [x] **Server announcer**: background task polls `/api/narration/events/recent`, posts epic moments to `ANNOUNCE_CHANNEL_ID`.
- [x] Config via `.env`: `DISCORD_BOT_TOKEN`, `API_BASE_URL`, `ANNOUNCE_CHANNEL_ID`. Run: start API → `python run_bot.py`.

### 4. Deferred to v0.6.0
- [ ] Next.js frontend dashboard (dark xianxia theme, Capacitor-ready).

## 🔧 Notes for future agents
- Gemini key must be a valid AI Studio key (`aistudio.google.com/apikey`). Invalid keys log a warning and fall through — check logs for `anromi.narration`.
- Groq's OpenAI-compat endpoint: `https://api.groq.com/openai/v1/chat/completions`.
- Gemini's OpenAI-compat endpoint requires `Authorization: Bearer <AI Studio key>`: `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`.
